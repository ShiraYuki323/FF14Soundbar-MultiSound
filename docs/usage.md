# FF14 音效技能栏｜使用教程

适用版本：Windows v1.0 源码版

制作者：黑魔高手

本工具基于 ChiZhou（迟昼）的开源项目 SR Voiceover Roulette 修改。

你可以给 FF14 的技能键配上自己的音效，也可以用轮盘随时选播。音效可以只在本机播放，或通过虚拟声卡送进 FF14、QQ、Discord 等语音软件。软件按 Windows 键位触发，游戏里施法是否成功不影响按键判定。

## 1. 第一次打开：先绑定一个技能试试

1. 按 [README](../README.md) 从源码启动，或运行自行构建的 EXE。如果托盘里还有旧版，先完全退出旧版。
2. 打开「技能栏」。一共三排，每排 12 格，底下是第 1 排。先选一个格子，在「触发按键」里录入你在游戏中已经使用的技能键，例如 `Ctrl+1`。程序里的按键设置不会修改游戏里的键位。
3. 先在「音效库」导入一个声音，再回到「技能栏」，在「绑定音效」里选中它并点「试听音效」。双击技能格也能试听。
4. 退回游戏或关闭窗口时选择「留在后台」，实际按一下刚才录入的键。第一次建议先确认自己耳机能听见，再接虚拟声卡。
5. 配好后点「保存套装」。以后也可以在软件左侧打开「使用教程」查看操作提示。

## 2. 技能栏怎么设置

### 方式一｜从截图识别技能图标和键位

源码版的图标库和 OCR 字形模板需要按 [README](../README.md) 自行准备。没有这些资源时，建议先手动录入键位。

- **现场截图**：先让游戏的技能栏显示在屏幕上，打开工具的「技能栏」→「截图并识别」。程序会暂时隐藏窗口。在截图界面拖出矩形，框住完整的两排或三排横向技能栏，松开鼠标就会开始识别。按 `Esc` 或右键取消框选。
- **导入已有截图**：进入「技能栏」→「截图导入」→「选择截图…」，在 Windows 文件窗口里打开原始截图。预览里拖动框出技能栏，再点「开始识别」。「清空」会清掉本次框选和识别结果，可以在同一张截图上重来。

每排按 12 格识别。框选时保留左右端和左上角的按键文字。规则横排适合截图识别，分散的小块、竖排和异形布局请用手动设置。原尺寸的截图通常比聊天软件压缩过的小图更容易辨认；如果末尾有空格，也把整排的范围留在框内，识别结果以预览为准。

识别结束后，先检查预览里的行数和格子位置，再处理标记：

| 预览标记 | 怎么处理 |
| --- | --- |
| 待确认 | 点这一格，对照截图里的完整技能图标和左上角的按键。可以点程序给出的候选，也可以直接录入正确键位。 |
| 图标待核 | 键位已经有结果，图标还需核对。点「选择职业与技能」补选，或点「图标留空」。 |
| 已确认 | 仍可点格子检查。建议特别检查 `O / 0`、`Q / O` 以及组合键。 |

「下一个待确认」可以跳到下一处。游戏里显示的 `c1`、`a1`、`s1` 分别是 `Ctrl+1`、`Alt+1`、`Shift+1`。如果一整排本来就是数字键顺排，可以用「填充整排」填写从 `1` 到 `=` 的 12 格，或选择带 Ctrl、Alt、Shift 的一组。混合键位的一排请逐格核对。

点「确认导入」后，识别结果会写入当前技能栏。**两排图只更新下面两排，三排图更新全部三排。这个操作更新键位和图标，原来各格的音效和音量会保留。** 如果完全没有识别到键位或图标，确认按钮不会开放；可以重新框选或手动补录。

### 方式二｜逐格手动设置

1. 点「手动设置」或直接选中目标技能格。
2. 点「选择职业与技能」，先选职业图标，再选技能。
3. 点「触发按键」，按下实际使用的快捷键。若同一按键已被其他技能格、轮盘或暂停占用，先处理冲突。
4. 通过「绑定音效」选声音，需要时调整这个格子的「音量」。暂时没有合适图标，也可以留空，先把键位和音效设好。

## 3. 按键触发、能力技和临时 GCD

工具窗口在前台或留在后台时，都可以用已绑定的按键播放音效。录入快捷键、编辑文字或数字、打开设置对话框时，触发会暂时停止。
### 普通技能：默认共用 2.5 秒冷却

「技能栏」页的「公共冷却」可调。比如设为 2.5 秒，按下普通技能 A 并成功播放后，接下来的 2.5 秒内再按 A 或另一个普通技能 B 都不会发声。冷却结束后，下一次按键才会触发；期间的按键不会排队补播。

### 能力技：每格单独防连按 1 秒

选中目标格，勾选「能力技 · 独立冷却」。能力技不占用普通技能的公共冷却，每个能力技各自有固定 1 秒的防连按。例如：普通技能 A 刚响过，这时插入能力技 B 和 C，B 和 C 都能独立发声；一秒内连按 B，只响第一次。

手动选图标或从截图匹配到已知技能后，如已准备 7.05 技能分类索引，软件会尝试自动判断，能力技格会显示青色「能」。宏、未知技能或判断有误时可以手动设定。想重新按图标判定，点「恢复自动」。

### 临时 GCD：一个技能键改变接下来几轮冷却

1. 选中会改变你出手节奏的技能格，先确认此格已经录入实际按键。
2. 点「临时 GCD…」，勾选「按下此格绑定键时启用」。
3. 填写「临时公共冷却」和「持续时间」，再点「保存」。举例：填 1.5 秒和 10 秒，表示按下此格键后，接下来的 10 秒内新开始的公共冷却按 1.5 秒计。
4. 实际按技能键测试。此格即使没绑定声音，仍可以启动临时计时。一轮已经开始的冷却按原时长结束；临时效果到期后，新一轮恢复使用基础冷却。效果期间连按同一格不会续时，另一个临时 GCD 技能触发时，以最后一次生效的设置为准。

这项功能调整的是**音效的播放冷却**。持续时间从按下设置好的键开始计算，适合按你自己的技能节奏设置。

### 连续同键自动加速

在「技能栏」打开「连续同键自动加速」。同一格第一次按正常速度播放，连续成功触发时通常每次增加 10%，最高为基础速度的 160%。换格或停顿后恢复。冷却内没响的按键不计数，试听也不会增加次数。这是全局开关；想单独调整某个声音，可以用音效参数。

## 4. 音效库：导入、试听、绑定和管理

### 导入自己的音频

1. 打开「音效库」→「导入音效…」，点「添加音效…」，可在 Windows 文件窗口多选。也可以从资源管理器把音频拖入程序。
2. 支持 WAV、MP3、OGG、FLAC、M4A。选中一行，点「试听所选文件」；这一步试听的是原文件。
3. 只想保留中间一句时，在该行设置截取的开始和结束时间。「直到结尾」会保留到原文件末尾。「统一音量」默认开启，不想改变响度可以取消勾选。
4. 点「开始导入」，逐行查看结果。相同内容和处理选项重复导入会跳过；同名但内容不同的音频会另存。音效导入后不会自动绑定，原文件也不会被移动或修改。

### 找到音效并绑定

- 用搜索框按名称找声音，或勾选「仅看未绑定」。音效库可以按名称、导入时间或时长排序。
- 点音效左侧的播放按钮试听。从技能栏也可以双击某个格试听绑定的声音。**试听只在本机播放，不会送进语音，也不会占用公共冷却。**
- 点某条音效的「绑定」，在出现的技能栏里点想要绑定的格子。同一个声音可以绑多格；点「完成」收起面板。误点可以用「撤销上次绑定」。列表会显示当前套装中绑定了该音效的技能图标和键位。
- 一格要绑定多个音效时，选中技能格，点「多音效…」。添加普通或组合音效，可上移、下移或移除，然后选择「列表循环」或「随机播放」并保存。列表循环每次成功触发播放一项，到末尾后回到第一项。随机播放每次抽一项，连续两次可能抽到同一项。
- 在音效库也可以先点「绑定」，勾选「追加到已有绑定」，再点技能格，把当前音效加到该格的列表末尾。

### 删除与恢复

在单条音效的菜单中点「删除」，可以删一条。要批量删除，就勾选多条，再点「删除选中」。确认窗口会显示受影响的技能格、套装和组合。普通音效会移入本地回收区，引用它的格子会暂时显示为缺失；点「撤销删除」可恢复上一次删除的音效及其原有引用。

### 进阶：变调、变速和组合音效

- **参数**：在音效库单条声音的菜单点「参数」，或在技能栏选中已绑定音效的格子后点「参数…」。可调单个声音的音量、基础播放速度、固定或随机变调，以及连击时如何变调、变速。先点「本地试听」再保存。音效参数由所有引用它的格子和套装共用；若只想调某个格子的音量，在技能栏改该格的「音量」。
- **组合音效**：点「音效库」→「新建组合」，双击库里的声音加入成员，选择按顺序全部播放、随机抽取、按次接龙或逐次累加。可以设置成员的顺序、触发延迟、截取和音量，试听后点「保存组合」。保存的组合会出现在音效库，可以像普通音效一样绑定，也可在编辑器里导出为 WAV。

## 5. 声音输出：自己听，或送进队伍语音

### 只在自己耳机里听

把 Windows 的默认播放设备设为日常使用的耳机或音箱。在工具的「声音输出」里，保持「把音效送进游戏语音（需要虚拟声卡）」关闭，就可以先按技能键或用轮盘测试本地播放。

### 让队友也能听见：以 VB-CABLE 为例

1. 先从 [VB-Audio 官网](https://vb-audio.com/Cable/)下载并安装驱动。按 Windows 提示授权，在官方安装器中点 **Install Driver**，完成后重启电脑，再回工具的「声音输出」点「重新检测」。已经装过的玩家可以直接选已有设备。
2. **先勾选「把音效送进游戏语音（需要虚拟声卡）」**。在工具的「虚拟声卡」里选择 **CABLE Input**，或点「选用此声卡」自动选中。程序把声音送到这里。
3. 在实际用于聊天的游戏或语音软件里，把麦克风输入选成 **CABLE Output**。把语音软件的扬声器输出留在日常耳机上。Windows 的默认播放、录音设备也可以保持原样。
4. 需要边说话边放音效，在工具的「采集麦克风」选真实麦克风。到「说话测试」点「开始测试」，检查音量条是否随说话跳动。只想传音效，可把「原声·送对方」调到 0%，虚拟声卡开关仍保持开启。
5. 在语音软件的麦克风测试里，实际用技能键或轮盘触发一次。若语音使用按键发言，测试时按住发言键。请用这个方法验证队友收到的声音，单击音效库的试听不会发送。

| 音量设置 | 调整的是哪一路 |
| --- | --- |
| 音效·送对方 | 队友听到的音效音量 |
| 原声·送对方 | 队友听到的真实麦克风音量 |
| 本地监听 | 自己耳机里听到的音效音量 |

开着语音输出时，可以勾选「音效也从自己的耳机里放出来（自己能听见）」。出现断续或爆音时，可小幅提高「缓冲余量」后再试；缓冲越大，播放延迟也会增加。

## 6. 音效轮盘

1. 默认长按 `Y`。轮盘会在鼠标位置附近展开，靠屏幕边缘时会调整显示位置。
2. 各格显示当前套装对应的技能图标与音效。移动鼠标到想选的一格，松开呼出键播放。绑定了多个音效的格子按设定的方式播放，和技能键共用同一个循环进度。没有选中音效时，松手可以关闭。
3. 滚轮切页。当前三排布局共有 5 页，每页最多 8 格。同一次运行中，重新打开会停在上次关闭的页面。
4. 打开「更多设置」→「安排轮盘音效…」，可选中条目「上移」「下移」，再点「保存顺序」。默认顺序是第 1 排、第 2 排、第 3 排，每排从左往右；要重置可点「恢复技能栏顺序」。轮盘顺序由所有套装共用。
5. 「更多设置」还可更改轮盘呼出键，以及轻按时重播上一个、播放下一个或不执行动作。如果游戏会锁住鼠标，轮盘选不中时，把「轮盘鼠标定位」切到「锁鼠标兼容」再试。
6. 只想用轮盘手动放梗时，到「技能栏」页打开「只播放轮盘音效」。技能键和轮盘轻按动作将停止触发，长按选中并松手仍可播放。

## 7. 窗口置顶、保存套装、暂停和退出

- **窗口置顶**：在「技能栏」页勾选「窗口置顶」，主窗口会保持在其他普通窗口上方。取消勾选即可恢复。程序会记住这个设置。
- **保存套装**：「保存套装」会用当前配置更新该套装；「另存为…」会把当前配置复制成一套新方案。「当前套装」的下拉框用来切换，「管理」可新建、重命名或删除。切换前先保存想保留的改动。
- **套装保存内容**：键位、图标、音效绑定、每格音量、公共冷却、能力技设置和临时 GCD 都随套装保存。音效库、单条音效参数和轮盘排序由各套装共用。
- **暂停与恢复**：默认快捷键是 `Ctrl+Shift+F12`，也可在「技能栏」「更多设置」或托盘菜单里操作。「更多设置」可改这个快捷键。触发按键在后台也会响应，打字或暂时不玩时可以暂停。暂停会停止当前音效，已开启的麦克风传输继续工作。
- **关闭窗口**：点右上角 `×` 后，选「留在后台」会继续响应快捷键；选「完全退出」会结束程序。留在后台后，也可从 Windows 托盘菜单退出。

## 8. 常见问题、日志与备份

| 遇到的情况 | 先检查什么 |
| --- | --- |
| 能试听，按技能键没声音 | 看是否处于暂停或「只播放轮盘音效」模式；确认当前套装的格子同时有正确按键和有效的音效绑定，再等公共冷却结束后试一次。 |
| 能力技跟普通技能一起被卡住 | 选中该技能格，确认「能力技 · 独立冷却」已勾选。 |
| 截图只能识别到一部分，或截图是黑屏 | 尝试原分辨率图片并框完整的两排或三排；独占全屏截不到时，改用游戏截图导入或无边框窗口。少数键位可以在预览里补录。 |
| 自己听见，队友听不见 | 查工具的语音输出开关、工具的 CABLE Input、语音软件的 CABLE Output 是否都选对；用轮盘或真实技能键播放来测试。语音软件的发言方式或降噪也可能影响结果。 |
| 队友听见音效，听不见说话 | 检查工具里的「采集麦克风」是否选到真实麦克风、「原声·送对方」是否大于 0%，再看「说话测试」的音量条。 |
| 设置过的音效突然显示缺失 | 检查是否删除过该声音，或是否换了数据目录。如果刚删除，可试「撤销删除」。 |

**反馈问题**：到「更多设置」→「导出诊断日志…」，在 Windows 的「另存为」窗口保存 ZIP。诊断包包含运行日志和版本环境信息。反馈时可以附上 ZIP、出现问题的操作和大致时间。

**备份或换电脑**：先完全退出程序。在 Windows 资源管理器地址栏输入 `%LOCALAPPDATA%\FF14Soundbar`，备份整个目录（含隐藏文件）。迁移时在目标电脑退出程序后恢复这份目录，启动程序后再检查当地的音频设备选择。只替换 EXE 升级时，正常情况下会继续读取原有的本机数据。
